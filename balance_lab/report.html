Game length & first player

Average turns per finished game: 8.34 (sd 2.72 over 1684 games). A very short average means the race to cell 24 is decided before mana even ramps up; a long tail means games stall in the mana-lock / deadlock pattern instead of resolving.

Deadlock draws: 0 of 1684 finished games (0.00%).

The engine picks the first player at random, so the first-player share is a clean measurement of turn-order value: 51.7% of decided games go to the first player — 95% CI [49.3%, 54.0%] on 1684 games. Anything far from 50% is a rule-level (not deck-level) balance question.

How this is produced — python balance_lab/run_lab.py --games 100 --workers N plays the 171 matchups × N games in parallel (18 decks = 6 main factions × 3 support factions; each deck is a fresh random 20-main + 10-support build validated by deck_rules.py). Each worker process plays into its own SQLite shard and the parent merges them into balance_lab/balance_lab.db — same games(game_id, state_json) schema as games/games.db, and the main DB is never touched. One row per game is appended to balance_lab/results.csv (matchup, winner, turns, positions, seed, temperature, the two full deck lists, …) — that CSV is the input of this page.
Regenerate — python balance_lab/report.py. Every percentage on this page is a direct count from results.csv; the per-game seed is logged, so any game can be re-played deterministically, and its final state is in balance_lab.db under its game_id.
Data quality — python balance_lab/run_lab.py --audit checks card conservation on every stored game (final zones vs the deck it started from) and writes audit.json; python balance_lab/repro.py --worst 3 replays a flagged game action by action. Known findings and their status: balance_lab/FINDINGS.md.
